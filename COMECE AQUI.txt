IA FINANCEIRA AZURE — COMO ABRIR

1. Abra um terminal nesta pasta.
2. Execute: npm run dev
3. Abra: http://127.0.0.1:5174/
4. Use “Acessar demonstração” na tela de login para testar a aplicação com dados fictícios.

Os dados da demonstração são fictícios e ficam neste navegador. A prévia local não usa login Microsoft nem banco Azure. Para encerrar, pressione Ctrl+C no terminal.

ARQUITETURA DA CÓPIA AZURE
- Node.js e Next.js no Azure App Service.
- Microsoft Entra ID pelo App Service Authentication.
- Azure Database for PostgreSQL com identidade gerenciada.

O aplicativo ainda não foi publicado em uma assinatura Azure. Consulte README.md para provisionar os recursos e conectar o App Service.
